# Google Gemini Prompt Best Practices

## Guidelines
1. **Direct Instruction**: Gemini responds best to clear, structured instructions without fluff.
2. **Context Window Utilization**: Leverage Gemini's expansive context window by providing complete documentation, source text, or datasets upfront.
3. **Structured System Instructions**: Use hierarchical headings and explicit output constraints.
4. **Safety & Grounding**: Instruct the model to cite facts directly from provided source material to prevent hallucination.
